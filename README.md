# Sektor

Vida pessoal num app de computador: finanças, tarefas, agenda e hábitos, com os dados na sua máquina.
Open source, em Electron. Integrações usam a chave de cada pessoa.

```bash
pnpm install
pnpm dev       # app em desenvolvimento
pnpm smoke     # prova do banco criptografado, sem abrir janela
pnpm package   # gera o app em apps/desktop/dist
```
